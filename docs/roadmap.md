# 功能规划

这里列的都还**没做**，是参考现在成熟的智能音箱和带屏音箱（小爱同学、天猫精灵、Echo Show 和 Alexa+、Nest Hub 和 Gemini）以及大模型最近的进展，挑出适合这台设备和这套架构的功能。已经有的功能见[根目录 README](../README.md#本仓库加的功能)，架构见[系统架构](architecture.md)。

工作量是粗估：**小**指一两天，**中**指三到五天，**大**指一周以上或者要先验证硬件。

## 看图问答

用户想要「帮我看下这是什么」。设备自带的摄像头在主线内核上用不了（定制传感器 s5kc505a，没有驱动，见[硬件限制](architecture.md#硬件限制)），可以换下面几种做法。网关已经有上游的视觉接口 `/mcp/vision/explain` 和视觉模型配置（`VLLM`：智谱 GLM-4V、通义千问 VL），只差图片从哪来。

| 做法 | 体验 | 工作量 |
| --- | --- | --- |
| **手机拍照（推荐）**：说「帮我看下这是什么」，屏幕上出一个二维码；手机扫码打开网关上的上传页，拍照上传；网关交给视觉模型，设备念出回答，照片和回答一起显示在对话里 | 多一步扫码，但手机摄像头清楚得多，也能传相册里的图 | 中 |
| USB 摄像头：设备的 USB‑C 口接一个 UVC 摄像头，客户端用 ffmpeg 拍一张 | 最像原生，但要先验证这个口在主线内核上能不能当 USB 主机用、供电够不够 | 中，先验证 |
| 米家摄像头截图：问「门口有人吗」时取米家摄像头的画面 | 小米云没有公开的截图接口，要逆向，不稳定 | 大，不建议 |

## 日常

| 功能 | 说明 | 工作量 |
| --- | --- | --- |
| **早安简报** | 说「早上好」或者设一个时间：念今天天气（要不要带伞）、今天的闹钟和提醒、几条新闻；屏幕上同时出一张卡片 | 小 |
| **屏幕待机页** | 空闲时显示大时钟、天气、下一个闹钟，可选家庭相册轮播（照片从手机扫码上传，和看图问答共用上传页） | 中 |
| **一步一步做菜** | 菜谱卡片进入「做菜模式」：一次念一步，说「下一步」「再说一遍」不用唤醒词；步骤里有时间的自动问要不要定倒计时 | 中 |
| **留言** | 「给爸爸留言：晚上我不回来吃饭」；下次有人唤醒，或者识别出是爸爸时先念出来 | 小（有声纹后更好） |
| **购物清单、待办** | 「把酱油加到购物清单」；手机扫码就能看清单，买完划掉 | 小 |
| **网络电台、播客** | 「放上海交通广播」「放一集某某播客」：电台用公开的直播流，播客用 RSS；和蓝牙音乐一样，说话时自动压低音量 | 中 |
| **白噪音、助眠** | 雨声、海浪，定时关；和睡眠时段配合 | 小 |
| **翻译** | 「这句用英语怎么说」已经能做；加一个对话翻译模式：两人轮流说，自动在中英之间互译 | 小 |

## 家居

| 功能 | 说明 | 工作量 |
| --- | --- | --- |
| **场景口令** | 「我出门了」：关灯、关空调，念一句今天的天气；「我睡了」：关灯、开夜灯、进入睡眠时段。在设置页编辑，存在设备上 | 中 |
| **主动告警** | 米家的水浸、门窗、烟雾传感器状态变了，设备主动响提示并念出来（夜里只亮屏） | 中 |
| **设备状态问答更聪明** | 「家里有没有没关的电器」「今天空调开了多久」（需要记录状态历史） | 中 |

## 孩子

家里有三岁宝宝，适合加一个**儿童模式**（设置页开关，或说「切换到儿童模式」）：

| 内容 | 说明 |
| --- | --- |
| 说话方式 | 换一个专门的提示词：短句、慢一点、用孩子懂的词，不讲吓人的内容；语音换童声音色 |
| 讲故事、儿歌 | 大模型现编短故事，可以指定主角（「讲一个小兔子刷牙的故事」）；儿歌用固定曲库 |
| 认知问答 | 「小狗怎么叫」「这是什么颜色」配上屏幕上的卡片图；等孩子大一点再加古诗、英语跟读、口算 |
| 时间限制 | 每天能聊多久、几点以后不陪聊，到点提醒「该睡觉啦」 |
| 家长查看 | 管理后台能看孩子问了什么 |

具体做哪些，最好按孩子的年龄和家里想要的来定。

## 大模型的新能力

| 功能 | 说明 | 工作量 |
| --- | --- | --- |
| **认出是谁在说话（声纹）** | 网关已经带了上游的声纹识别对接（`voiceprint`），要另外跑一个声纹服务（3D-Speaker）。认出是谁之后：回答按人调整、记忆分人、孩子说话时自动用儿童模式 | 中 |
| **实时语音模型** | 端到端的语音大模型（千问 Omni 实时版、豆包实时语音）直接听、直接说：延迟更低，语气更自然，能听出情绪。缺点是贵，工具调用能力比文字模型弱，可以只在闲聊时用 | 大 |
| **方言识别** | 现在的 X-ASR 只认普通话和英语。老人说上海话时，可以改用支持方言的识别（FireRedASR2 支持 20 多种方言，但在这台网关的 CPU 上一句话要 1 秒以上；或者用云端的千问 ASR） | 中 |
| **分人的长期记忆** | 现在一台设备一段记忆。有声纹后可以每个人一段：爸爸爱喝什么、孩子几点睡 | 小（在声纹之后） |
| **定时任务交给大模型** | 「每天早上七点告诉我今天要不要带伞」「每周五提醒我交水电费」：大模型到点自己查、自己判断再念，不只是固定的提醒文字 | 中 |
| **网关挂了也能用** | 网关或网络断了时，用本地命令词识别兜底：定闹钟、调音量、开关米家的灯 | 中 |

| 功能 | 说明 | 工作量 |

| **同音字理解** | 已做：提示词里教大模型按读音理解识别错的词（「先辈怎么做」→ 鲜贝/扇贝），直接按最可能的意思回答 | — |
