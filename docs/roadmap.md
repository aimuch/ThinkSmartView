# 功能规划

2026-11-09 这一轮把上一版规划里的功能基本都做了（客户端 0.1.613～0.1.624）。同一天下午又做了后台的登录、状态、工作原理和模型接入，跟进了上游的新提交和 issue（客户端 0.1.625～0.1.626、系统层 0.2.4）。界面都先在[设计画布](https://claude.ai/artifact/EY4tpyoxYbT8h3saGzAWaw)上画过（第 6～16 块），架构见[系统架构](architecture.md)。

## 还没做

| 功能 | 为什么还没做 | 要做的话 |
| --- | --- | --- |
| 用家人的声音播报（声音复刻） | 要百炼 Key；阿里云的声音复刻接口几个版本的文档对不上（接口地址、能用的模型名），没有 Key 没法验证 | 填好百炼 Key 后再接：设备录 10～20 秒，网关创建音色，天气播报、留言可以选「用妈妈的声音念」 |
| 方言识别 | 本地的 X-ASR 只认普通话和英语；能认方言的本地模型（FireRedASR2）在这台网关的 CPU 上一句要 1 秒以上 | 后台「语音识别」里改用云端的阿里百炼（千问 ASR，支持多种方言），填百炼 Key |
| 内置摄像头 | 传感器 s5kc505a 没有主线内核驱动 | 接 USB 摄像头前要先验证 USB‑C 口能当主机用 |
| 实时语音大模型 | 端到端语音模型（千问 Omni 实时版等）贵，工具调用弱 | 只给闲聊用，需要百炼 Key |
| 声纹自动切儿童模式的童声 | 现在认出孩子后只改说话方式，声音在连接建立时就定了 | 网关按每句的说话人切换音色 |
| 用真实录音挑语音识别模型 | 要录家里人平时说的话 | 方法见 [scripts/asr-eval/](../scripts/asr-eval/README.md) |
| Claude Code 用国产模型 | DeepSeek、Kimi、智谱、千问都有 Anthropic 兼容接口，把 Claude Code 的 ANTHROPIC_BASE_URL 指过去就能用；但网关上没装 Claude Code，改了也验证不了，而且 Anthropic 不支持这种用法 | 想用的话先在网关上装 Claude Code；国产模型直接用上面的 DSH 更省事 |
| Codex CLI | 后台卡片一直是「即将支持」，上游也还没做 | 等上游 |
| Grok Bot 新发送接口的真机验证 | 2026-11-05 起网关的 sendPrompt 返回 502（上游 issue #4），已改成被拒时走 Cursor 后台；这台网关上没登录 Grok Bot，没法实测 | 在后台 Grok Bot 页登录后叫一次，看日志里有没有「改走 Cursor 后台发送」 |
| 功放的设备树（上游 image issue #3） | 喇叭现在能响；改设备树要重编内核、重刷，网友的补丁是配他们自己的驱动测的 | 以后重编内核时一起改 |
| ath10k 组密钥更新断线（上游 image issue #2） | 这台设备连续 16 小时没出现过一次 `failed to install key`，镜像里应该已经带了修好的驱动 | 有人遇到再说 |
