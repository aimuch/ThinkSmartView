# 功能规划

2026-11-09 这一轮把上一版规划里的功能基本都做了（客户端 0.1.613～0.1.624）。界面都先在[设计画布](https://claude.ai/artifact/EY4tpyoxYbT8h3saGzAWaw)上画过（第 6～13 块），架构见[系统架构](architecture.md)。

## 已经做了

| 功能 | 怎么用 | 需要什么 |
| --- | --- | --- |
| 天气定时播报、早安简报 | 设置 →「天气播报」：几个时间、每天/工作日/周末；中午前的那次可顺便播今天的提醒和新闻 | — |
| 住宅地址 | 「天气播报」卡片里按住说地名；没说地点的天气问题按它查 | — |
| 拍照问答 | 说「帮我看下这是什么」或点顶栏相机，手机扫码拍照 | 后台「大模型 → 看图模型」填 Key（智谱 GLM-4V-Flash 免费） |
| 首页外观 | 设置 →「外观」：5 套主题、8 个形象、首页显示哪些内容和顺序 | — |
| 照片生成卡通形象 | 「外观」里点「用照片生成」，手机拍正脸，选画风 | 百炼 Key（千问 TTS 或千问 VL 里填的那个） |
| 网关后台界面 | 侧栏底部「界面」：主题、强调色、宽度、侧栏、密度、菜单顺序；表格可排序、拖列、调列宽、拖行 | — |
| 儿童模式 | 设置 →「儿童模式」：年龄、每天最多聊多久、几点后不陪聊、童声 | — |
| 待机页、家庭相册 | 设置 →「待机页」；相册用手机扫码一次传多张 | — |
| 做菜模式 | 菜谱卡片上点「开始做菜」或说「开始做菜」；之后直接说「下一步」 | — |
| 场景口令 | 「以后我说『我出门了』，就……」 | 用到米家的步骤要先登录米家 |
| 留言 | 「给爸爸留言：……」，首页便签 | — |
| 清单 | 「把酱油加到购物清单」；设置 →「清单 → 手机看」 | 手机和小麦在同一个 Wi‑Fi |
| 网络电台、助眠声 | 「放东方广播」「放雨声，半小时后关」；设置 →「电台和助眠声」 | 电台要能上网 |
| 定时任务 | 「每天早上七点告诉我今天要不要带伞」 | — |
| 主动告警 | 设置 →「主动告警」：漏水、睡眠时段门窗打开 | 米家登录，有水浸/门窗传感器 |
| 翻译模式 | 「帮我们中英互译」 | — |
| 家人声音（认出是谁） | 设置 →「家人声音」：说名字、念三句 | 网关上的声纹模型（已装在 models/voiceprint/） |
| 断网兜底 | 网关连不上时直接说「音量大一点」「现在几点」「关掉所有灯」 | 关灯要能连米家云 |
| 同音字理解 | 自动 | — |

## 还没做

| 功能 | 为什么还没做 | 要做的话 |
| --- | --- | --- |
| 用家人的声音播报（声音复刻） | 要百炼 Key；阿里云的声音复刻接口几个版本的文档对不上（接口地址、能用的模型名），没有 Key 没法验证 | 填好百炼 Key 后再接：设备录 10～20 秒，网关创建音色，天气播报、留言可以选「用妈妈的声音念」 |
| 方言识别 | 本地的 X-ASR 只认普通话和英语；能认方言的本地模型（FireRedASR2）在这台网关的 CPU 上一句要 1 秒以上 | 后台「语音识别」里改用云端的阿里百炼（千问 ASR，支持多种方言），填百炼 Key |
| 内置摄像头 | 传感器 s5kc505a 没有主线内核驱动 | 接 USB 摄像头前要先验证 USB‑C 口能当主机用 |
| 实时语音大模型 | 端到端语音模型（千问 Omni 实时版等）贵，工具调用弱 | 只给闲聊用，需要百炼 Key |
| 声纹自动切儿童模式的童声 | 现在认出孩子后只改说话方式，声音在连接建立时就定了 | 网关按每句的说话人切换音色 |
| 用真实录音挑语音识别模型 | 要录家里人平时说的话 | 方法见 [scripts/asr-eval/](../scripts/asr-eval/README.md) |
